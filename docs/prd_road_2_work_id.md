## 1. Ringkasan Produk

Road2Work.id adalah platform **AI Interview Readiness** yang membantu mahasiswa, fresh graduate, dan career switcher mempersiapkan interview kerja secara lebih realistis dan terarah.

User memilih target role, memberikan konteks pengalaman melalui **upload CV** atau **isi profil singkat**, lalu menjalani **live voice interview** bersama AI HRD. Setelah interview selesai, sistem memberikan dashboard evaluasi berisi kekuatan jawaban, area yang perlu diperbaiki, contoh jawaban yang lebih baik, dan rekomendasi latihan berikutnya.

Road2Work.id tidak berfokus sebagai job portal, melainkan sebagai platform latihan interview berbasis AI yang membantu user mengubah pengalaman mentah menjadi jawaban interview yang lebih kuat, relevan, dan berbasis evidence.

---

## 2. Latar Belakang Masalah

Banyak mahasiswa dan fresh graduate sebenarnya memiliki pengalaman yang relevan, seperti project kuliah, organisasi, freelance, bootcamp, magang, atau lomba. Namun, saat interview, pengalaman tersebut sering tidak tersampaikan dengan baik.

Masalah utama yang ditemukan:

1. User punya pengalaman, tetapi bingung cara menjelaskannya secara profesional.
2. Jawaban interview terlalu umum dan kurang evidence.
3. User belum tahu cara menghubungkan pengalaman dengan role yang dituju.
4. User belum terbiasa menjawab interview secara lisan.
5. User tidak tahu bagian jawaban mana yang sudah kuat dan mana yang perlu diperbaiki.
6. Latihan interview biasa cenderung statis, tidak adaptif, dan tidak menggali jawaban user.

Karena itu, Road2Work.id dibuat untuk membantu user berlatih interview dalam kondisi yang lebih mendekati situasi nyata, dengan feedback yang spesifik dan bisa ditindaklanjuti.

## 13. User Flow Detail

### 13.1 Landing Page Flow

**Trigger:** User membuka website.

**User Action:** Klik “Mulai Latihan Interview”.

**System Response:** User diarahkan ke login/sign up jika belum login.

---

### 13.2 Role Selection Flow

**Trigger:** User klik “Start New Interview”.

**User Action:**

1. Memilih role family.
2. Memilih target role.

**System Response:** Sistem menyimpan role target dan mengarahkan user ke Interview Context Setup.

---

### 13.3 Interview Context Setup Flow

**Trigger:** User selesai memilih role.

**User Action:** Memilih salah satu:

1. Upload CV
2. Isi Profil Singkat

**System Response:** Sistem memproses input dan membangun interview context.

**Business Rule:** User tidak dapat lanjut interview tanpa memberi minimal konteks.

---

### 13.4 Live Interview Flow

**Trigger:** User klik “Start Interview”.

**System Action:**

1. AI menghasilkan pertanyaan utama.
2. UI menampilkan HRD WebM state “Asking”.
3. User menjawab dengan voice.
4. UI berubah menjadi “Listening”.
5. Sistem melakukan STT.
6. UI berubah menjadi “Thinking”.
7. AI mengevaluasi jawaban.
8. Jika perlu, UI berubah menjadi “Clarifying”.
9. AI memberikan pertanyaan klarifikasi.
10. Jika tidak perlu, sistem lanjut ke pertanyaan berikutnya.

---

### 13.5 Result Dashboard Flow

**Trigger:** Interview selesai.

**System Action:**

1. Menghitung final readiness score.
2. Menentukan strengths.
3. Menentukan improvement areas.
4. Membuat before-after answer improvement.
5. Membuat next practice recommendation.
6. Menampilkan dashboard.

## 24. Risks and Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Voice-only terlalu berisiko | Interview gagal saat demo | Siapkan fallback demo/internal text mode |
| STT lambat | UX terganggu | Gunakan loading state dan batasi durasi audio |
| GenAI hallucination | Feedback tidak valid | Gunakan prompt guardrail dan validasi data user |
| Model TensorFlow kurang akurat | Scoring tidak kuat | Jadikan supporting score |
| Scope melebar | MVP tidak selesai | Lock scope P0 |
| Deployment AI berat | Demo terganggu | Siapkan local fallback/video demo |
| Integrasi terlambat | Flow end-to-end gagal | Gunakan API contract dan mock data sejak awal |

Road2Work.id adalah produk AI Interview Readiness yang fokus membantu user melatih dan meningkatkan kualitas jawaban interview berdasarkan role target dan konteks pengalaman pribadi.

```txt
Role Selection
↓
Upload CV / Isi Profil Singkat
↓
Context Extraction
↓
Live Voice AI HRD Interview
↓
AI Evaluation + Clarification
↓
Evidence-Based Result Dashboard
```

Dengan pendekatan ini, Road2Work.id memiliki value yang jelas, scope yang realistis, dan inovasi yang dapat ditunjukkan melalui voice interview, adaptive clarification, Evidence Ladder, dan dashboard feedback yang actionable.
