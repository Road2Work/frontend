1. Tujuan Dokumen
Dokumen ini mendefinisikan API Contract Road2Work.id v2.3 untuk kebutuhan integrasi antara Frontend Next.js, Backend Express.js, FastAPI AI Service, PostgreSQL Database, dan Admin Panel.
API Contract ini sudah menyesuaikan overview terbaru Road2Work.id, terutama pada flow Upload CV, flow manual profile, HRD Interview State, speech-to-text 90 detik, dan adaptive interview antar session.
1.1 Perubahan Penting v2.3
Interview ulang tidak dianggap sebagai sesi kosong; sistem membaca evaluasi interview sebelumnya.
Create interview session dapat membawa practice memory seperti previousInterviewSummary, previousWeaknesses, askedQuestionHistory, dan improvementFocus.
Pertanyaan baru harus menghindari pertanyaan yang sama persis secara default.
Kompetensi yang sama tetap boleh ditanyakan ulang dengan wording berbeda jika weakness belum membaik.
Dashboard Next Best Action menjadi salah satu input untuk menentukan fokus interview berikutnya.
Recording policy tetap fixed: mic otomatis menyala setelah HRD selesai bertanya, timer 90 detik berjalan otomatis, silence tidak mematikan mic.
State utama HRD tetap konsisten: idle, asking, listening, thinking, clarifying, completed, dan error.
2. Arsitektur Komunikasi
Next.js Frontend
↓
Express.js Backend API Gateway
↓                    ↘
PostgreSQL Database       FastAPI AI Service
↓                    ↗
Career Readiness Dashboard / Admin Analytics
Frontend hanya memanggil Express Backend API Gateway.
Express Backend bertanggung jawab atas auth, ownership, quota, session state, interview history, dashboard, dan penyimpanan hasil.
FastAPI AI Service menangani AI extraction, role fit, interview context, question generation, STT, answer evaluation, clarification, TensorFlow inference, dan result generation.
Practice memory untuk adaptive interview dibentuk oleh Backend dari database, lalu dikirim ke FastAPI sebagai input terkontrol.
Dashboard mengambil data dari backend/database, bukan langsung dari AI service.

5. Core Business Rules
Rule
Description
BR-01
User harus login sebelum membuat professional profile.
BR-02
User dapat memilih jalur Upload CV atau Isi Profil Manual.
BR-03
Jika user upload CV, sistem melakukan AI extraction dan Role Fit Ranking.
BR-04
Jika user tidak upload CV, user wajib memilih Domain, Role Family, Target Role, dan mengisi profil singkat.
BR-05
Setiap hasil AI extraction harus bisa direview dan diedit user.
BR-06
Role Fit Ranking hanya digenerate pada jalur Upload CV.
BR-07
Pada jalur manual, sistem langsung memakai Target Role yang sudah dipilih user.
BR-08
Role Fit Score tetap dapat dihitung untuk dashboard pada semua jalur.
BR-09
User wajib confirm selected role sebelum interview pada jalur CV.
BR-10
1 user mendapatkan 5 free interview sessions.
BR-11
1 interview session berisi 3-5 main questions.
BR-12
Pertanyaan pertama interview adalah self introduction/perkenalan diri.
BR-13
Setelah HRD selesai memberikan pertanyaan, mic otomatis menyala dan timer 90 detik dimulai.
BR-14
Mic tetap menyala walau user diam; silence tidak boleh menjadi auto-stop.
BR-15
Voice answer selesai ketika user menekan Mic Off atau timer mencapai 90 detik.
BR-16
Setiap main question maksimal memiliki 1 clarification, dan setiap session maksimal memiliki 3 clarification.
BR-17
Setelah interview selesai, sistem wajib update Career Readiness Dashboard.
BR-18
Career Summary hanya bisa diunduh jika Career Readiness Score >= 90.
BR-19
Jika user melakukan interview lagi pada role yang sama, sistem harus membaca evaluasi interview sebelumnya.
BR-20
Sistem harus menghindari pertanyaan yang sama persis secara default melalui askedQuestionHistory.
BR-21
Kompetensi yang sama boleh ditanyakan ulang dengan wording berbeda jika weakness belum membaik.
BR-22
Jika target role berubah, role context dihitung ulang, tetapi weakness umum seperti STAR, clarity, confidence, dan evidence tetap dapat digunakan sebagai improvement context.
BR-23
Dashboard Next Best Action menjadi input untuk menentukan improvementFocus pada interview berikutnya.
BR-24
Pertanyaan lama boleh diulang hanya jika retryMode = true atau user memilih mode latihan ulang/focus retry.

6.7 HRDInterviewState
State ini mengikuti overview produk dan digunakan sebagai visual state utama HRD Interview Stage. Detail teknis recording disimpan melalui RecordingPolicy agar state tetap mudah dipahami oleh frontend dan user.
State
Fungsi
idle
HRD siap memulai interview
asking
HRD sedang mengajukan pertanyaan
listening
HRD sedang mendengarkan jawaban user; mic otomatis aktif dan timer 90 detik berjalan
thinking
AI sedang memproses jawaban, menjalankan STT, evaluasi, dan decision next question
clarifying
HRD meminta klarifikasi atau detail tambahan
completed
Sesi interview selesai
error
Terjadi error teknis pada interview stage
type HRDInterviewState =
| "idle"
| "asking"
| "listening"
| "thinking"
| "clarifying"
| "completed"
| "error";

11.3 Interview Stage Flow — 90 Seconds
Display current question
↓
HRD State: asking
↓
After HRD question finished -> mic automatically starts
↓
HRD State: listening
↓
Timer 90 seconds starts automatically
↓
User answers; mic stays on even if user is silent
↓
User Mic Off OR 90s timer timeout
↓
POST /interviews/sessions/:sessionId/voice-answer
↓
HRD State: thinking
↓
If nextQuestion exists -> asking/clarifying
If isCompleted true -> completed -> dashboard/result
11.4 Repeat Interview Adaptive Flow — New in v2.3
User clicks Latih Interview Lagi from dashboard
↓
Frontend calls POST /interviews/sessions with practiceMode=adaptive_from_history
↓
Backend checks profile, selected role, quota
↓
Backend loads previous interview result, weaknesses, score breakdown, asked question history, latest feedback, and next best actions
↓
Backend builds adaptivePracticeMemory
↓
Backend calls FastAPI /v1/interview/build-context and /v1/interview/generate-question
↓
AI generates new question focused on weaknesses and avoids exact repeated questions
↓
Interview continues adaptively
↓
Result and dashboard update again
