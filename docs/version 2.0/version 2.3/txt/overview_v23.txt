1. Ringkasan Produk
Road2Work.id adalah platform AI Career Readiness yang membantu mahasiswa, fresh graduate, career switcher, dan pencari kerja mempersiapkan diri menuju dunia kerja secara lebih terarah.
Pada MVP capstone ini, Road2Work.id berfokus pada interview readiness yang didukung oleh data profil profesional user. Sistem membantu user membangun atau membaca profil profesional, memahami skill dan bukti pengalaman, memperoleh rekomendasi role yang sesuai, menjalankan adaptive voice interview, lalu memperbarui Career Readiness Dashboard.
Road2Work.id bukan hanya aplikasi latihan interview. Produk ini diarahkan sebagai career roadmap platform yang membantu user memahami posisi kesiapan mereka saat ini, mengetahui gap yang harus diperbaiki, dan mengambil langkah berikutnya menuju pekerjaan yang lebih baik.
Core experience Road2Work.id tetap mempertahankan Adaptive HRD Interview Stage, yaitu halaman interview berbasis visual HRD menggunakan short loop video/WebM. User menjawab secara langsung menggunakan voice, sistem melakukan speech-to-text secara internal, mengevaluasi kualitas jawaban, mendeteksi kelemahan, dan menghasilkan pertanyaan klarifikasi jika dibutuhkan.

3. Problem Statement
Banyak kandidat pemula memiliki pengalaman seperti project kuliah, organisasi, freelance, bootcamp, lomba, magang, atau tugas akhir, tetapi belum mampu menjelaskannya dengan kuat dalam interview.
Masalah utama yang diselesaikan Road2Work.id:
1. User bingung menjelaskan pengalaman secara profesional.
2. Jawaban interview sering terlalu umum dan kurang bukti konkret.
3. User belum tahu cara menghubungkan pengalaman dengan role target.
4. User belum terbiasa menjawab interview secara lisan.
5. User sering tidak tahu apakah jawabannya sudah cukup kuat atau belum.
6. Platform latihan interview biasa cenderung statis dan tidak menggali jawaban user secara adaptif.
7. User membutuhkan dashboard yang menjelaskan skor kesiapan, gap, dan langkah perbaikan secara mudah dipahami.
Road2Work.id hadir untuk membantu user mengubah pengalaman mentah menjadi jawaban interview yang lebih relevan, jelas, dan berbasis evidence.

11. Interview System dan Logic STT 90 Detik
Interview pada Road2Work.id menggunakan konsep adaptive voice interview. User menjawab menggunakan microphone. Selama mic masih aktif, jawaban dianggap masih berlangsung. Jawaban selesai ketika user menekan Mic Off atau durasi maksimal tercapai.

11.2 Update Baru: Logic Mic Otomatis dan Durasi 90 Detik
Kondisi
Logic Sistem
Implikasi UI/UX
HRD memberikan pertanyaan
Setelah pertanyaan HRD selesai ditampilkan/dibacakan, state berpindah dari Asking ke Listening.
User tidak perlu menekan mic untuk mulai menjawab karena mic otomatis aktif saat state Listening.
Mic otomatis menyala
Browser microphone aktif otomatis sesuai permission yang sudah diberikan user sebelum interview.
Indicator mic aktif harus jelas agar user tahu jawaban sedang direkam.
Timer 90 detik dimulai
Countdown 90 detik berjalan bersamaan dengan recording.
Timer tampil kecil namun jelas pada Interview Stage.
User diam di tengah jawaban
Mic tetap menyala dan recording tetap berjalan. Sistem tidak menghentikan rekaman hanya karena silence.
Silence dianggap bagian dari proses berpikir user, bukan tanda jawaban selesai.
User selesai sebelum 90 detik
User dapat menekan Mic Off / Selesai Menjawab.
Mic Off menjadi sinyal eksplisit bahwa jawaban sudah selesai dan siap diproses.
Timer mencapai 90 detik
Recording otomatis berhenti dan jawaban dikirim ke STT.
Sistem dapat menampilkan copy: Waktu menjawab selesai, jawabanmu sedang diproses.
STT selesai
Transcript disimpan internal, lalu state berpindah ke Thinking saat AI mengevaluasi jawaban.
Jika jawaban kurang jelas, state berpindah ke Clarifying; jika tidak, lanjut ke Asking berikutnya atau Completed.
Catatan Implementasi STT 90 Detik
Durasi jawaban untuk MVP ditetapkan maksimal 90 detik. Tidak ada auto-stop berbasis silence detection. Stop condition hanya dua: user mematikan mic sebagai tanda selesai, atau timer 90 detik habis.
11.3 Interview State Frontend
State
Fungsi
Implikasi UI / Sistem
Idle
HRD siap memulai interview.
Menampilkan HRD WebM idle loop, CTA Start Interview, dan memastikan microphone permission sudah diberikan sebelum sesi dimulai.
Asking
HRD sedang mengajukan pertanyaan.
Question bubble ditampilkan, HRD WebM masuk state asking, user belum menjawab, dan mic belum merekam sampai pertanyaan selesai.
Listening
HRD sedang mendengarkan jawaban user.
Mic otomatis menyala, timer 90 detik otomatis berjalan, recording tetap aktif walau user diam, dan user dapat menekan Mic Off/Selesai Menjawab sebelum waktu habis.
Thinking
AI sedang memproses jawaban.
Recording berhenti, audio dikirim ke STT, transcript disimpan internal, lalu AI mengevaluasi jawaban, score, evidence level, dan weakness.
Clarifying
HRD meminta klarifikasi atau detail tambahan.
Muncul jika jawaban kurang jelas, kurang evidence, missing tools, missing impact, atau kontribusi pribadi belum terlihat. Setelah pertanyaan klarifikasi selesai, state kembali ke Listening.
Completed
Sesi interview selesai.
Sistem menghasilkan interview result, memperbarui Career Readiness Dashboard, dan menampilkan CTA untuk melihat hasil atau latihan ulang.
State utama HRD Interview Stage mengikuti konsep visual produk. Detail teknis seperti recording, auto mic, timer 90 detik, STT, dan API call tidak dijadikan state terpisah, tetapi menjadi behavior di dalam state Listening dan Thinking.

12.4 Adaptive Interview Antar Session
Jika user melakukan interview lagi pada role yang sama, sistem tidak boleh mengulang pertanyaan yang sama persis secara default. AI HRD harus membaca evaluasi dari interview sebelumnya, termasuk score breakdown, weakness, evidence level, feedback terakhir, dan daftar pertanyaan yang sudah pernah ditanyakan.
Tujuannya adalah membuat sesi latihan berikutnya terasa seperti kelanjutan proses improvement, bukan interview baru yang kosong dari konteks.
Prinsip adaptif antar session:
Pertanyaan baru diprioritaskan pada area yang masih lemah dari interview sebelumnya.
Sistem menghindari pertanyaan yang sama persis, kecuali user memilih mode latihan ulang atau retry focus.
Kompetensi yang sama boleh ditanyakan ulang dengan wording berbeda jika weakness belum membaik.
Jika target role berubah, role context dihitung ulang, tetapi weakness umum seperti STAR structure, confidence, clarity, dan evidence tetap bisa digunakan sebagai konteks improvement.
Dashboard Next Best Action menjadi salah satu input untuk menentukan fokus interview berikutnya.
Data dari Interview Sebelumnya
Fungsi untuk Interview Berikutnya
Score breakdown
Menentukan area skor terendah yang perlu dilatih ulang, misalnya STAR Structure atau Evidence Specificity.
Detected weaknesses
Menjadi prioritas arah pertanyaan adaptif, seperti missing impact, weak evidence, atau low role relevance.
Evidence level
Menentukan apakah user perlu didorong dari claim/skill menuju context, impact, atau measurable result.
Asked question history
Mencegah AI menanyakan pertanyaan yang sama persis pada sesi berikutnya.
Latest interview feedback
Menjadi konteks bahasa feedback agar sesi berikutnya terasa personal.
Next best actions
Mengarahkan fokus latihan berikutnya sesuai rekomendasi dashboard.
Contoh: pada interview pertama user lemah di evidence dan missing impact. Pada interview kedua, AI HRD tidak mengulang persis “Ceritakan pengalaman membuat dashboard”, tetapi dapat bertanya: “Ceritakan satu pengalaman ketika kamu memakai data untuk mengambil keputusan, lalu jelaskan tools, kontribusi pribadi, dan dampaknya.”

Clarifying question dapat menjadi: “Bisa kamu jelaskan tools yang digunakan, bagian yang kamu kerjakan sendiri, dan dampak dari dashboard tersebut?”

25. Definition of Done MVP
1. User bisa login/signup.
2. User bisa memilih jalur upload CV atau isi profil manual.
3. Pada jalur CV, sistem bisa extract CV, membuat professional profile draft, user bisa review/edit, dan sistem bisa generate Role Fit Ranking.
4. Pada jalur manual, user bisa memilih Domain, Role Family, Target Role, mengisi profil singkat, review/edit profile, lalu sistem langsung memakai selected target role tanpa Role Fit Ranking.
5. Sistem bisa extract skill, tools, experience, achievement signals, dan evidence.
6. User bisa masuk ke live voice interview.
7. HRD WebM stage tampil dengan state yang jelas: Idle, Asking, Listening, Thinking, Clarifying, dan Completed.
8. Pertanyaan pertama adalah perkenalan diri dan pertanyaan berikutnya adaptif.
9. Mic otomatis menyala setelah HRD memberikan pertanyaan.
10. Timer 90 detik berjalan otomatis saat mic aktif.
11. Mic tetap menyala walau user diam.
12. User bisa mematikan mic sebelum 90 detik sebagai tanda selesai menjawab.
13. STT menghasilkan transcript internal.
14. AI bisa mengevaluasi jawaban.
15. AI bisa menghasilkan clarifying question jika jawaban kurang jelas.
16. Sistem bisa menghitung final readiness score.
17. Career Readiness Dashboard ter-update setelah interview.
18. Jika user interview lagi, sistem menggunakan evaluasi interview sebelumnya untuk menentukan improvement focus.
19. Sistem bisa menghindari pertanyaan yang sama persis melalui asked question history.
20. Dashboard menampilkan Career Readiness Score, Evidence Score, Role Fit Score, Interview Readiness, Profile Completeness, Strengths, Gaps, Before–After Answer Improvement, Next Best Action, dan Activity Timeline.
21. Admin panel basic tersedia untuk domain, role family, role, skill/tools, dan analytics sederhana.
22. README tersedia.
23. Deployment staging tersedia atau fallback demo siap.
26. Kesimpulan
Overview baru Road2Work.id memperjelas bahwa platform ini bukan hanya aplikasi mock interview, tetapi AI Career Readiness Platform.
26.1 Flow Final yang Harus Dijaga
Path
Flow Final
Upload CV Path
Upload CV → AI Extract Profile → Review & Edit Profile → Role Fit Ranking → Confirm Role → Build Interview Context → Interview → Dashboard.
Manual Path
Pilih Domain → Pilih Role Family → Pilih Target Role → Isi Profil Singkat → AI Extract Profile → Review & Edit Profile → Build Interview Context → Interview → Dashboard.
26.2 Core Loop Road2Work.id
Profile -> Role -> Practice -> Feedback -> Improve
Perubahan penting yang digabung dalam versi ini:
Road2Work.id diarahkan sebagai AI Career Readiness Platform, bukan hanya mock interview.
Professional Profile menjadi fondasi role fit, interview context, evidence score, dan dashboard.
Role Fit Ranking hanya muncul pada jalur Upload CV.
Manual path langsung memakai target role yang dipilih user.
Dashboard utama menjadi pusat hasil setelah interview, bukan hanya result page terpisah.
Interview tetap voice-first dan menggunakan HRD WebM Interview Stage.
Interview ulang membaca practice memory dari hasil sebelumnya agar pertanyaan berikutnya lebih personal dan tidak mengulang pertanyaan yang sama persis.
Mic otomatis menyala setelah HRD memberikan pertanyaan dan timer 90 detik otomatis dimulai.
Mic tetap menyala walau user diam, dan user bisa mematikan mic sebelum 90 detik sebagai tanda selesai menjawab.
Pertanyaan interview berjumlah 3–5 dan adaptif berdasarkan jawaban user serta competency target.
Pertanyaan diawali dengan perkenalan diri, lalu dapat mengarah ke interest, need of learning, self confidence, skill, solution skill, predictive based, predictive-based recruitment, dan agile culture.
Clarifying question dihasilkan berdasarkan weakness detection, bukan asal GenAI.
Dashboard menggunakan pendekatan hybrid: rubric, role-skill matrix, Evidence Ladder, TensorFlow supporting model, dan GenAI wording.
Dengan alur ini, Road2Work.id memiliki arah produk yang lebih kuat, user experience yang lebih jelas, dan fondasi teknis yang lebih rapi untuk dikembangkan sebagai capstone project maupun future product.
